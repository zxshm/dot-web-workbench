连接说明
  1. 打开本机 Codex，保持账户登录。
  2. 将本程序的独立 MCP 端点通过 Secure MCP Tunnel 连接到你的 Dot。
  3. 在Dot中订阅“工作台请求”事件，让它读取并转交新请求。

Dot 尚未连接时，消息会保存在本机等待接收。程序不会把排队状态显示成已送达。

本机记录位于 data/。邮件使用自行配置的 SMTP 账户；邮件状态“服务器已接收”不等于已进入收件箱。

密钥由 Windows 加密，保存在当前用户目录；重新打开程序会自动恢复连接。
